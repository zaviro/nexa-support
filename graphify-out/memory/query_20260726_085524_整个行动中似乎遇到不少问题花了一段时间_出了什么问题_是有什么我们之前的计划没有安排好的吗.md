# Q: 整个行动中似乎遇到不少问题花了一段时间，出了什么问题？是有什么我们之前的计划没有安排好的吗？

## Answer

Expanded from original query via graph vocab: [plan, workflow, scope, scaffold, environment, install, skills, github, worktree, testing, quality, verification]. 结论：产品范围计划完整，主要缺口是缺少独立的工程 bootstrap 预检阶段，没有先冻结任务边界、unborn 仓库状态、devenv 内精确版本、工具职责和执行顺序。可避免的问题包括过早形成后续失效的交接快照、未预判非空根目录的 T3 TTY 行为、未先解决 worktree 所需首个 commit、先用宿主 Bun 安装再对齐 devenv Bun、Biome 配置漂移及未引用 heredoc。技能更名、GitHub API 最终一致性、Nix 与 Chromium 冷启动属于外部变化或必要成本。改进方案是先做只读 preflight，再按 temp scaffold → devenv lock → Bun frozen install → quality DAG → 单次全量验证 → 最终交接执行。
